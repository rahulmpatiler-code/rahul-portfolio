# Rahul M. Patil — Portfolio

This is a single-file responsive portfolio website. The profile image is embedded inside `index.html`, so no separate image hosting is required.

## Publish with GitHub Pages

1. Sign in to GitHub.
2. Create a **new public repository** named `rahul-portfolio`.
3. Upload `index.html` to the repository root.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/ (root)**, then Save.
7. After GitHub finishes deploying, the portfolio URL will be:

https://rahulmpatiler-code.github.io/rahul-portfolio/

The URL is only live after the repository and GitHub Pages deployment are completed.
